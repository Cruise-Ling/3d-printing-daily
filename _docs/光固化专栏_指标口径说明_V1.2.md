**取代**：V1.1（2026-11-12）、V1.0（已作废）
**适用范围**：`resin-line.html`（光固化产品线 · 用户口碑看板）

# 一、本期为什么升版本

V1.1 的口径只覆盖单一品牌（创想三维 7 个机型）、竞品只统计「被点名」、渠道把 B站/Reddit 记为封锁。四件事变了，必须升版本并留下断点：

| 变更 | V1.1 | V1.2 | 影响面 |
|---|---|---|---|
| 机型谱系 | 创想 7 个机型 | 四品牌 26 个机型（创想 11 / Elegoo 5 / Anycubic 5 / Phrozen 5） | 机型维度、矩阵、KPI 机型覆盖 |
| 机型归属算法 | 子串匹配，裸别名参与 | 词边界正则 + 最长匹配优先 + hashtag 拆分 + 裸通用词禁用 | **30 条存量里 15 条归属被纠正** |
| 竞品口径 | 只统计「被点名」，且只在我方样本里算 | 「对比语境」（文本双向命中，不分归属）+「竞品自有样本」双口径，分母分离 | 竞品面板、竞品样本 KPI |
| 渠道覆盖 | B站 blocked、Reddit blocked（按限流可用） | B站 auto（warmup+Referer 实测 code=0）、什么值得买 auto（分类页 + 正文）、Reddit blocked（返回 HTML 中间页） | 渠道面板、国内样本量 |

> **断点提示**：V1.1 及更早的机型归属结果**不得**与 V1.2 做机型维度趋势对比。KPI 总量类指标（总声量、负面占比）仍可比，但分母已从 19 条扩到 60 条，负面对比须同时看分子分母。

# 二、核心指标定义

## 2.1 声量

统计区间内与该主体相关的独立内容条数。同一主题重复镜像只算 1 条；不同 `postId` / `bvid` / 文章 ID 的独立反馈分别保留。

## 2.2 有效样本（KPI 主口径）

声量剔除以下内容后的样本，作为情感与问题点的分母：

- 零互动官方投放
- 批量同文案
- 低信号联盟带货（含 Amazon 联盟链接、返利链接）
- 官方与媒体信源
- 超采样上限的条目（见 2.6）
- 无实质表述的动态条目（纯提问、纯展示、配件商品页、榜单 listicle、教程）

KPI 主口径用有效样本，副文本给全量对照。分子分母必须同时给出。

## 2.3 负面占比

`（负面 + 非常负面）÷ 有效样本`。分母为 0 时显示「—」，**不写 0.0%**（空白 ≠ 无负面）。

## 2.4 机型覆盖

`当前品牌筛选下「有数据的机型数」÷「在榜机型数」`。品牌=全部时分母为全谱系 26 个。机型未命中但有品牌线索的，归属到品牌级（显示品牌 chip，机型记「未归属机型」）。

## 2.5 竞品样本与对比语境

以竞品机型为**主体**的有效样本数（来自竞品定向检索词）。与「对比语境」是两个不同分母：

- **对比语境（竞品被点名）**：分母是当前筛选下的**对比语境样本数**——即**文本里同时出现我方与竞品机型**的样本，衡量「用户拿谁做对比」；
- **竞品自有样本**：分母是**竞品**样本，衡量「竞品自己有多少讨论」。

### 2.5.1 为什么对比语境必须按文本双向命中判定

机型归属是**单赢家**：一条 `Creality Halot-Mage S vs Elegoo Saturn 4 Ultra 16K` 只会归给别名更长的一方（本例归 Elegoo，落进竞品桶）。如果对比语境只在「我方样本」里统计，这类真正的对比样本会被整条排除，面板上段恒为 0——看起来像「用户从不拿竞品对比」，实际是口径假象。

因此对比语境改用文本级双向命中：只要同一条文本里我方机型与竞品机型都命中，就计入对比语境，**不看这条最终归给谁**。同时逐条落 `ownMentioned` / `competitorMentioned` / `comparisonContext` 三个字段，面板可下钻回原文核对。

两者禁止交叉推导，也不允许用 3~10 条竞品样本宣称竞品负面率高于或低于我方。竞品样本 <3 条时负面占比显示「—」。

> 披露要求：对比语境样本占比通常很低（本批全量 6 条、有效口径 1 条 / 60），面板分母行必须同时给「当前筛选分母」与「全量对照」，禁止只写小的那个数制造"竞品没人讨论"的观感。

## 2.6 单机型采样上限

同一机型最多入页：我方 10 条、竞品 5 条，按发布时间倒序取最近。超限条目**保留原文**、标「动态」、不计入情感分母，可在全量口径查看。设上限的原因：竞品检索词单轮可召回 25×N 条，不限量会让竞品样本淹没我方用户原声。

# 三、机型归属规则

1. **词边界正则**：`(?<![a-z0-9])别名(?![a-z0-9])`，杜绝子串误命中。
2. **最长匹配优先**：`Saturn 4 Ultra 16K` 不会被 `Saturn 4 Ultra` 抢走。
3. **裸通用词禁用**：`one / max / ray / mage / sky / lite / play / r6 / mono / mars / saturn / jupiter / mega / mighty / revo / sonic` 不得单独作别名（`R6` 会命中相机、`PLAY` 会命中普通动词、`MAGE` 会命中 image）。
4. **hashtag 拆分**：`#CrealityHalotR6` → `Creality Halot R6`，社交平台连写标签也能识别。
5. **品牌兜底**：机型未命中但命中品牌词（creality / 创想 / halot / elegoo / anycubic / phrozen 等）时归属到品牌级。
6. **注入层每次重算**：归属由注入时按当前别名表重新判定，因此改别名表或扩机型谱系后，历史条目自动纠正，不需要清空 `seen` 重采。

实测：V1.1 的 30 条存量里 15 条归属错误或缺失（`MAGE` 命中 `image`、`RAY` 命中 `gray`/`array`），修复后仅 2 条确实无法判定（正文未提任何品牌机型）。

# 四、渠道状态（2026-11-13 复测）

| 渠道 | 状态 | 采集方式 | 备注 |
|---|---|---|---|
| Creality 官方论坛 | 自动 | Discourse `/search.json` + `/t/{id}.json` | 唯一可规模化拿到完整正文的一手源；日更按 3 天窗口，场景词日更易 429 |
| YouTube | 自动 | Data API v3 search + videos + commentThreads | 免费额度 1 万 unit/日；单轮实测约 1309 unit；品牌官方频道内容按「官方」降档 |
| Bilibili | 自动 | 搜索 API（先 GET 首页 warmup 拿 cookie，再带 Referer） | 取代 V1.0「直连 412 = blocked」的结论；单轮 9 个关键词可召回 100+ 条 |
| 什么值得买 | 自动 | 分类页 `/fenlei/3ddayinji/` 列表 + 文章页正文 | 站内搜索页返回 202 空壳不可用，但分类页是真实 SSR HTML；标题/摘要预筛后只取命中条正文 |
| Reddit | 封锁 | — | `www` 搜 403；`old.reddit` 返回 HTTP 200 但正文是「Welcome to Reddit」HTML 中间页，0 条 entry，非 Atom feed |
| 小红书 / 抖音 / 知乎 / 微博 / 贴吧 | 登录墙 | — | 登录态仅能截图抄录 |
| Amazon / 京东 / 天猫 / 淘宝 | 不可得 | — | 官方 API 不给评价，需 Keepa / Rainforest 等商业数据源 |
| 专业评测站 | 人工补录 | — | WP REST 401 |

**稀疏渠道窗口**：B站按 120 天、什么值得买按 180 天滚动召回，靠 `seen` 差集保证不重复入库，因此「入库日 ≠ 发布日」；论坛与 YouTube 按 3 天日更窗口。

# 七、不可外推声明

1. 入库样本 ≠ 全量口碑。主源是问题导向社区（官方论坛）+ 评测导向内容（YouTube / B站 / 值得买），天然偏负面或偏「开箱评测」。
2. 国内样本仍显著少于海外样本，国内结论只能定性参考。
3. 竞品样本量小（单机型 ≤5 条），只能看「问题点结构是否相似」，不能比负面率高低。
4. 情感与问题点为 **AI 逐条语义复核**，不是需求方人工签字，保留人工改判通道。
