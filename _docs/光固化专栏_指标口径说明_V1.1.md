# 四、分母规则（最易产生结论冲突的地方）

1. **KPI 主口径用有效样本（19）**，副文本同时给全量口径（30）对照；问题点 Top、信源结构、样本质量面板各自显式标分母。
2. **不同模块分母可能不同**，页面每处标题右侧标注当前分母，**禁止跨面板交叉比对推导结论**。
3. **分母为 0 显示「—」，不写 0.0%**。空白不等于无负面。
4. 问题点与信源结构按**条去重**后计数，保证「面板数字 = 点开后明细条数」；一条反馈可命中多个问题点，问题点合计可大于样本数。
5. 官方 / 客服 / 工单一律只做分类汇总，不进情感分母；泛讨论单列。
6. 同一主题帖的重复镜像按 K3 mirrors 纪律**只算 1 条**（`post:102008` 与 `post:102091` 同属 topic 46600）。

# 五、采集与去噪规则

## 5.1 六步归一化 + 五道相关性闸门

六步：抓取 → 字段归一 → 语种 / 机翻 → 时间窗 → 去重 → 候选池落盘。

五道闸门：① 品类语境 ② 主体 ③ 同名异物排除 ④ 正文 ≥40 字符 ⑤ 时间窗 / 去重。

> **YouTube 额外强语境**：`RESIN_STRICT`（resin / 光固化 / HALOT / FEP / 料槽 / 曝光 等）必须命中；命中 `FDM_MARKERS`（K2 / Ender 3 / filament / nozzle / CFS 等）时必须有明确光固化主体，否则剔除。起因是首跑 13 条里 12 条是 K2 / Ender 3 的 FDM 视频。
> **同名异物**：`Mars` / `Saturn` / `Mono` / `Photon` / `Halot` 在天文、汽车、游戏语境命中时排除。

## 5.2 三层窗口与增量幂等

L1 日更（近 3 日）、L2 周期回捞（近 30 日）、L3 全量校验（12 个月）。

- 采集器按 `_resin_seen.json` 双线差集防重复抓；注入器按 `_resin_uid_map.json` 以 `candKey` upsert，**重跑不换 uid、不重复写入**。
- 候选池按 mode 分文件（`_resin_candidates_{backfill|daily}_YYYYMMDD.json`），预标层与注入层均**合并全部候选池**再按 `candKey` 去重——这是 B1 修掉的日更会清空历史标注的坑。
- 日更裁剪查询词（机型前 6 + 品类前 2，场景词留给 L2/L3），避免论坛 429。

# 六、情感与问题点标注规则（V1.1 核心变更）

1. **采集器绝不判情感**。情感、问题点、P0、`countInVolume` 只在标注层产生。
2. **AI 逐条语义复核**：读标题 + 完整正文 + 上下文逐条判定，走 K3 §12.4「候选池只是候选、受控词表、保留改判通道」纪律。写回 `_resin_labels.json` 时 `confirmed=true`、`needsReview=false`、`labelSource=ai-semantic-review`、`reviewNote=判定依据`。留痕见 `_resin_ai_review.md`。
3. **受控词表 12 类**（`resin_config.json` 的 `problemPoints`）：打印精度与尺寸误差 / 曝光与光源一致性 / 离型膜与料槽寿命 / 树脂适配与气味 / 平台附着力 / 屏幕寿命与坏点 / 软件与切片 / 清洗固化配套 / 价格与首发信心 / 竞品对比与定位 / 售后与配件供应 / 包装与物流。**长尾根因写进 `summaryCn`，不自造类目**；脚本会校验词表外类目并拒绝写入。
4. **保守判定**：正负词同时命中降中性；求助 / 故障型标题（`how to` / `problem` / 否定词）不因正文出现正面词就判正面；「抱怨但对整体满意」判中性，不为平衡硬标正面。拿不准标 `countInVolume=false` 留待下次，**不为凑数硬标**。
5. **人工改判通道保留**：编辑 `_resin_labels.json` 对应条目的 `sentiment` / `problemPoints` / `isP0` / `countInVolume`，把 `lock=true` 后重跑注入，人工结论不会被覆盖。
6. **规则预标仍有作用，但只做候选**：`_resin_prelabel.py` 产出 `needsReview=true` 的待复核清单（`_resin_review_inbox_YYYYMMDD.md`）；日更链中 `STATUS: NEEDS_REVIEW` 时**拒绝注入**，必须逐条语义复核后才能 `--finalize`。
7. > ⚠ **披露义务**：标注为「AI 辅助语义复核，非需求方人工签字」。验收条目 #2「人工抽样核对偏差 ≤10%」**尚未完成**，需需求方指派口径确认人执行。

# 九、样本边界与合规

1. **入库样本 ≠ 全量口碑**：主源为问题导向社区，好评通常一句话、问题反馈才长篇论证，按信息量挑样本天然偏负面。本批有效样本负面 52.6% **不可外推为产品负面率**。
2. **渠道偏斜**：30 条全部海外、30 条中 25 条来自 Creality 官方论坛（自有社区），国内口碑与第三方平台完全缺位。页面与任何引用本报告的材料都必须披露。
3. AI 语义复核存在误判可能，且**未经需求方人工签字**；报告须同时给出置信度披露与待复核条数（当前 0 条待复核）。
4. 仅保留公开可获取内容、保留原文直链与存档、不展示用户个人身份信息；不引入登录态小号，不绕过平台条款。
5. 本看板只做市场与用户声音的风险发现与趋势判断，不替代售后与工单系统。
