# 三、改造方案（下一期独立批次，本批不实施）

## 3.4 必须避开的三个坑

1. **KPI 改名歧义**：「总声量」改成跟随筛选后，用户会以为全站声量缩水了。方案是保留名称但副文本强制写「当前筛选后 N 条 / 全库 M 条」，与光固化 V1.1 的「主口径 + 全量对照」一致；**不要默默改数**。
2. **分母为 0 显示「—」**：筛选后可能一条不剩，`(n/0*100).toFixed(1)` 会出 `NaN%`。H3C 首版踩过，改造时要复用光固化已有的空分母保护。
3. **别一次推三页**：建议先只改 mBox（26 条，样本最小）双跑一周、人工比对数字，再推软件（622 条）与全彩（66 条）。三页同时改，一旦断言红很难定位是哪套 KPI 分支。
