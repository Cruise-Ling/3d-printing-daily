# 三、核心指标口径

| 指标 | 定义 | 页面呈现 |
|---|---|---|
| 声量 | 统计区间内与该机型相关的独立内容条数；同一作者同平台同类内容去重；同一主题不同回复按 postId 分别保留 | KPI「总声量」 |
| 有效样本 | 声量剔除零互动投放、批量同文案、官方与媒体、无实质表述后的样本 | KPI 主口径 |
| 负面占比 | （负面 + 非常负面）÷ 有效样本数 | KPI，副文本给全量对照 |
| 泛讨论 / 动态 | 提及该机型但未形成实质评价的内容（`entryKind:"动态"`、`countInVolume:false`） | 单列统计，不进情感分母 |
| P0 风险 | 命中安全 / 批量质量 / 虚假宣传 / 售后拒保四类书面规则 | KPI + 明细徽标 |
| 信源类型 | 用户 / 官方 / 媒体 / 社区综述 / KOL | 信源结构面板，支持一键剔除官方与媒体 |
| 互动量 | 点赞、评论、播放等平台公开互动指标 | 明细展示，**不参与情感判定** |
| 有效样本占比 | 有效样本 ÷ 全量样本 | 样本质量面板，目标 ≥70% |

# 四、分母规则（最易产生结论冲突的地方）

1. **KPI 主口径用有效样本**，副文本同时给全量口径对照；问题点 Top、信源结构、样本质量面板显式标注各自分母。
2. **不同模块分母可能不同**（全量声量 vs 有效样本），页面每处标题右侧标注当前分母，**禁止跨面板交叉比对推导结论**。
3. **分母为 0 时显示「—」，不写 0.0%**。空白不等于无负面，这是 H3C 首版已踩过的坑。
4. 问题点与信源结构按**条去重**后计数，保证「面板数字 = 点开后明细条数」；一条反馈可命中多个问题点，问题点合计可大于样本数。
5. 官方 / 客服 / 工单一律只做分类汇总，不进情感分母；泛讨论单列。

# 五、采集与去噪规则

## 5.1 五道相关性闸门

1. 品类语境闸门：命中 `resin / SLA / MSLA / LCD / 光固化 / 树脂 / 离型膜 / 曝光 / 料槽 / 清洗固化` 等语境词；
2. 主体闸门：命中机型别名、竞品名或 Creality 品牌 + 光固化语境；
3. 同名异物排除：`Mars / Saturn / Mono / Photon / Halo` 等词在天文、汽车、显示器、游戏语境命中时排除；
4. 信号门槛：正文 ≥40 字符；
5. 去重：postId / 正文哈希 / 跨平台同稿镜像归并。

## 5.2 三层窗口与增量

L1 日更（近 3 日）、L2 新闻周期（近 30 日）、L3 全量校验（12 个月）。采集器按 `_resen_seen.json` 双线差集，`uid` 按发布日连续分配并持久化，重跑不换号、不重复写入。

## 5.3 去噪三条

| 标记 | 判定 | 处置 |
|---|---|---|
| `zero_interaction_official` | 官方账号 + 点赞 ≤1 + 回复 0 | 排除出 KPI 主口径 |
| `same_text_cluster` | 24 小时内同文案 ≥3 条 | 排除出 KPI 主口径 |
| `short_window_burst` | 6 小时内集中发布 ≥8 条 | 标记提示，不自动排除 |

# 六、情感与问题点标注规则

1. 情感分「非常负面 / 负面 / 中性 / 正面 / 非常正面」五档，页面须标明**规则预标**属性。
2. **采集器绝不判情感**。情感、问题点、P0、生命周期由标注层 `_resin_prelabel.py` 规则预标，每条 `needsReview=true`。
3. 保守规则：正负词同时命中一律降「中性」；求助 / 故障型标题（含否定词、how to、problem、crash 等）强制转「中性」并置 `forceReview=true`，置信度 0.20。
4. 问题点按命中词数取前 3 个，避免一条内容污染多个面板。
5. 人工改判通道：编辑 `_resin_labels.json` 对应条目，把 `confirmed` 设为 `true`、`needsReview` 设为 `false`，重跑预标与注入即可，人工结论不会被覆盖。
6. 海外原文保留原文与直链；**中文摘要 / 译文待机翻服务接入，本期标「译文待补」，不编造译文**。

# 七、P0 判定规则

| 类别 | 判定关键词 | 触达要求 |
|---|---|---|
| 安全 | 起火、冒烟、漏电、灼伤、有毒、fire、smoke、toxic | T+1 工作日推责任人 |
| 批量质量 | 批量、批次、每台、recall、widespread | 同上 |
| 虚假宣传 | 参数虚标、误导、false advertising、misleading | 同上 |
| 售后拒保 | 拒保、推诿、refuse warranty、denied rma | 同上 |

规则以配置表形式存于 `resin_config.json` 的 `p0Rules`，避免主观化。**当前未接飞书 / 责任人推送通道**，本期只做页面标记，登记为下一期 P0。

# 九、样本边界与合规

1. **入库样本 ≠ 全量口碑**：主源为问题导向社区，好评通常一句话、问题反馈才长篇论证，按信息量挑样本天然偏负面（H3C 论坛实测入库负面 55.6% vs 全量 12.5%）。页面与报告必须披露，禁止外推。
2. 情感判定为规则结果，存在误判；报告须说明置信度与待复核条数。
3. 仅保留公开可获取内容、保留原文直链、不展示用户个人身份信息；不引入登录态小号，不绕过平台条款。
4. 本看板只做市场与用户声音的风险发现与趋势判断，不替代售后与工单系统。
