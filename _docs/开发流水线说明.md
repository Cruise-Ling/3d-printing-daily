# 专栏开发流水线说明

四个专栏页（K3 / mBox / 软件 / 全彩）的源码、数据与生成方式。页面结构规则见同目录《专栏页面结构规范_v1.3》。

## 一图看懂

```
_col_shell.html  模板（五段骨架 + 全部 CSS + 渲染函数）
      │  _build_column.py 读取 _*_items_norm.json，注入 __DATA__
      ▼
creality-mbox.html / software-columns.html / fullcolor-columns.html   产物（自包含单文件，直接发布）
creality-k3.html  不走生成器，单页直写
```

**改版式必须改 `_col_shell.html`，再跑生成器。直接改产物，下次生成即丢失。**

## 目录与职责

| 文件 | 职责 |
|---|---|
| `_col_shell.html` | 三页共用模板：骨架、CSS、S2/S3/S4/S5 渲染函数 |
| `_nav.html` | 侧栏导航片段（四页同源，改一处全站同步） |
| `_build_column.py` | 生成器：组装数据 → 注入模板 → 写产物 |
| `_col_collect_*.py` | 采集器：sw 论坛 / mbox / fc 全彩 / yt 视频 / rd 实采 / github 缺陷单 |
| `_col_normalize.py` | 归一：字段映射、`countInVolume`、`sourceType` 透传 |
| `_col_sw_external.py` | 软件专栏外部四源聚合 + 闸门（标题级 / 正文级 / 综合版） |
| `_reddit_search.py` / `_smzdm_search.py` | Reddit RSS、什么值得买分类页 |
| `_col_s2_layout.py` / `_col_drop_version.py` / `_k3_plat_filter.py` | 一次性改造脚本：S2 并排、下线版本维度、K3 渠道筛选 |
| `_*_items_norm.json` | 归一后的数据源（页面内容的唯一来源） |
| `_col_tr_*.json` | 译文缓存（英文条目 → 中文段） |

## 跑一次

```bash
python _build_column.py            # 生成 mbox / 软件 / 全彩 三页
python _build_column.py --only sw  # 只生成软件专栏
python _build_column.py --nav-only # 只同步侧栏（含 K3 与首页）
```

改完务必做两步自检，不要靠肉眼：

1. 无头浏览器量 `.main` 直接子元素间距，应只有 12 / 24 两个值；
2. 量 `#topicGrid` 每张卡 `height`，同组内必须相等。

## 约定

- **密钥不入库**：推送脚本（`_push_*.py`）里的 GitHub token 一律不进仓库，需要推送时用环境变量注入。
- 备份文件（`_bak_*`）、`__pycache__`、中间态（`*_salvaged.json` / `*_union.json`）已由 `.gitignore` 排除。
- 产物是自包含单文件（数据内联、ECharts 本地化），不依赖任何 CDN 或外链资源。
